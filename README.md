# glslib

A Python package for graphics and simulation utilities.

## Installation

Install from source:

```bash
pip install -e .
```

## Quick Start

```python
from glslib import greeting

print(greeting("World"))
# Output: Hello, World!
```

## Development

### Setup

```bash
pip install -e ".[dev]"
```

### Running Tests

```bash
python -m unittest discover tests/
```
